# Approach Guidance Overview

`uv run engineeringagent approach` is the canonical entrypoint for how to work with repository guidance in this project.

Use `uv run engineeringagent approach list` to discover approved user and contributor-facing guidance topics.

Use `uv run engineeringagent approach <topic_id>` to open one topic from the local registry by stable topic id.
